--- layout: default title: "Journals" permalink: /journals/ description: "Every academic journal connected to KU Business — through research Ideate has covered, editorial roles our faculty hold, or both." --- {% comment %} Journals are intentionally NOT a curated _data/ list like topics.yml — the set of journals grows every time an article or a faculty member's editorial service is added, so this page derives the full list automatically from two sources instead: 1. article.journal (set per-article in the CMS, optional) 2. faculty.editorial_service[].journal (set per-faculty, optional) Liquid has no native way to flatten an array built inside a loop, so editorial-service journals are collected via capture+split below — a standard Jekyll workaround, not a bug. The ONE thing that does come from a data file is the premier flag: _data/journals.yml (edited in the CMS under Site Settings > Journals) is a list of journal names with a "premier" checkbox. It never adds a journal to this page — it only decides which already-listed journals get the premier treatment (bold name, highlighted box, badge, and the Premier sort/filter). Names are matched case-insensitively, then exactly. {% endcomment %} {% capture service_journals_raw %}{% for f in site.faculty %}{% if f.editorial_service %}{% for es in f.editorial_service %}{{ es.journal }}|||{% endfor %}{% endif %}{% endfor %}{% endcapture %} {% assign service_journals = service_journals_raw | split: "|||" %} {% assign article_journals = site.articles | map: 'journal' | compact %} {% assign all_journals = article_journals | concat: service_journals | uniq | sort_natural %} {% comment %} Lowercased names of every journal flagged premier, for the per-journal lookups below. {% endcomment %} {% assign premier_names = site.data.journals.items | where: 'premier', true | map: 'name' | join: '|||' | downcase | split: '|||' %}
